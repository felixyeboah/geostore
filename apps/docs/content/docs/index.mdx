Geostoresgh is a Ghana-focused store. Customers browse the catalogue, pay with mobile money, card, or cash on delivery, and track fulfilment. Administrators publish products, manage stock, and move orders through delivery.

## Start locally

1. Copy `.env.local.example` to `.env` and set `BETTER_AUTH_SECRET`.
2. Run `pnpm install`, `pnpm db:up`, `pnpm db:push`, and `pnpm db:seed`.
3. Create an admin with `pnpm --filter @repo/scripts create:user`.
4. Start the workspace with `pnpm dev`.

The storefront runs at `http://localhost:3001`; the account and admin app runs at `http://localhost:3000`.

## Payments

Set `STORE_PAYMENT_PROVIDER=mock` for Playwright and offline local work.

For Reevit test payments:

```bash
npm i -g @reevit/cli
cd apps/saas
reevit init --goal full --checkout-page -
```

Copy `REEVIT_*` values into the repo-root `.env`, then:

```bash
reevit listen --forward-to http://localhost:3000/api/webhooks/reevit
reevit doctor --webhook-url http://localhost:3000/api/webhooks/reevit
```

Live launch needs a Reevit live key plus a connected Ghana provider (Paystack or Hubtel).
