Admin overview — round 3

Rounds 1 and 2 both missed. Looking at how Shopify, Squarespace, Etsy, Fresha and PandaDoc actually build admin screens, the thing all six of my earlier mockups were missing wasn't styling — it was the application shell. No sidebar, no store switcher, no global search, no avatar, no product thumbnails. A bare content column can't look like a finished product no matter how the type is set.

What's new in this round
  • Full app shell — store switcher, grouped navigation with an order count, global search with ⌘K, notification bell, signed-in user
  • Product thumbnails on every order, best-seller and low-stock row, plus customer avatars
  • Designed tiles instead of stock photos, so nothing depends on an external image host
  • Brand purple carried through logo, active nav, primary button and the chart — present but not decorative
  • Soft one-pixel shadows and 11px radii rather than flat hard borders
